Web client parity implementation (`src/web/main.ts`, `src/web/style.css`)

Implement all Android items-view features in the web client while retaining the existing lit-html functional-template architecture, fail-fast mutation flow, and WebSocket sync.

### Implementation Notes
- New pure helpers exported for tests: `filterSearchQueryTiered` (port of `ReminderMatcher.filterSearchQueryTiered`), `formatSnoozeUntil` (port of `MainActivity.formatSnoozeUntil`), `exportToMarkdown` / `importFromMarkdown` (port of `MarkdownRemindersUtil`).
- Task cards gain: click-to-edit text, Mark Done, Punt (dialog with presets + custom), Unpunt (punted tasks), Undo Done (done tasks when revealed via `#done` query), Share, Delete.
- `#every`/`#repeat` tags styled secondary, `#notify` tags styled accent-subtle, matching item rendering in `RemindersAdapter`.
- Focus profiles and active profile set stored in `localStorage`; search query and section collapse state also persisted per browser.
- Import applies items as `create` mutations; punt timestamps inside imported `<time>` tags cannot be applied via the current phone mutation set and are ignored (tracked as known limitation).
