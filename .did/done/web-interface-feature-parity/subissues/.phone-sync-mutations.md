Phone sync mutation additions (`ServerSyncManager.applyAction`)

Extend the phone-side action set so web (and CLI) clients reach parity with local Android actions.

### Mutations
- `edit` (`target`, `text`): update reminder text via `ReminderDao.updateText`-equivalent entity copy; recompute recurrence interval from new text.
- `unpunt` (`target`): clear `snoozeUntil` so the task returns to Active.
- `undone` (`target`): clear `isDone` and strip any `#done` tag from text, mirroring `undoMarkDone`.
- `done`: when the reminder has a recurrence tag (`#every`/`#repeat`), punt it forward by the recurrence interval instead of marking it done, mirroring `MainActivity.markReminderDone`.

### Known Limitation
- Imported reminders with future punt timestamps cannot set `snoozeUntil` through `create`; would need an extended create payload if wanted later.
