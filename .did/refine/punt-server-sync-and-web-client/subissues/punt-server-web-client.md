Build offline-capable web client (PWA) for Punt server

Develop a web client (Progressive Web App) served directly by the Punt backend server over local network HTTP.
The web client acts as an interactive mirror of the user's Android phone.
Task mutations (creating, editing, punting, marking done) initiated in the web interface are sent to the server to be applied to the phone. If the phone is offline or unreachable on the local network, the mutation fails and the user is notified.

### Web Client Capabilities
- **Direct Origin Connection**: Served directly by the backend server (`http://<host>:<port>`).
- **Phone Mirror**: Renders the phone's active and punted tasks.
- **Fail-Fast Mutations**: When user adds or edits a task in the web UI, it sends the request through `/api/tasks/mutate`. If the phone does not confirm, the web UI rejects the edit and warns the user that the phone is unreachable.
- **Pairing UI**: Displays active single-use pairing codes and host address generated by the server for phone pairing.
- **UI Matching**: Follows Punt's minimal text interface guidelines (`bg_card`, high contrast typography, active/punted sections, search and focus pipelines).
